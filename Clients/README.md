# Portfolio — Thomas Durand

Portfolio développeur frontend React + Tailwind CSS.

## Stack
- React 18 + Vite
- Tailwind CSS 3
- React Router v6
- Framer Motion
- React Hook Form + Zod
- EmailJS

## Scripts
- `npm run dev` — serveur local
- `npm run build` — build de production
- `npm run preview` — preview du build
- `npm run lint` — linter
- `npm run format` — formatter
